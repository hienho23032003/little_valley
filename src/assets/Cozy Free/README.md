# Cozy Fantasy RPG UI - Free Sample

Organized locally on September 11, 2026 for ZSSGameLab.

## Contents

32 PNG files: 24 UI component/state files and 8 farming/gathering icons. Intended for a small seed-selection and item-information panel.

This folder contains 32 source PNG files. Counts include size and state variants, not unique designs. INCLUDED_ASSETS.csv records exact paths, dimensions, source paths and SHA-256 hashes. PNG files are grouped into ui_components, icons and, where included, backgrounds. Source filenames and image bytes are preserved.

## Usage

Use PNGs as graphics in your own UI system. Add text, layout, input, interaction and gameplay logic in your project. Inspect native sizes before scaling. Selected outlines may use larger canvases than normal slots; align by the visual center. Bar fills need appropriate positioning and masking. No validated 9-slice settings are supplied.

## Edition boundaries

PNG only. No PSD, fonts, engine project, runtime system or verified complete screen templates are included. Free is included in Starter; both are subsets of the source Full Pack. Backgrounds, where supplied in Starter, are whole scene images, not separate props or crop sprites.
